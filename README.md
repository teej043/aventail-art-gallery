# aventail-art-gallery

Live preview gallery of sprites, animations and portraits for Aventail SRPG, with approval status for each asset.

**Live site:** https://teej043.github.io/aventail-art-gallery/

## Structure

This is a single-page application (SPA) that displays game art assets organized by character unit.

- **index.html** - SPA gallery interface
- **roster.json** - Asset metadata and approval status for each unit
- **EDITING.md** - Instructions for updating the gallery
- **files/\<unit\>/** - Asset files organized by character (sprites, animations, portraits)
